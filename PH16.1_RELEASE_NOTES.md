# RescueVoice PH16.1 — Release Hardening

Release gates:
- Frontend TypeScript/Vite build
- Backend unit/integration/E2E tests
- PH15 adversarial suite
- API route compatibility
- Harness verification contract
- Loop terminal error contract
- Local demo launcher

Safety contract:
Consequential actions remain behind verification, explicit consent, server-side Policy Gate authorization, allow-listed tools, idempotency, audit logging, and human final-decision ownership.

Local demo:
- Backend: `python start.py`
- Frontend: `npm install && npm run dev`
- API: `http://localhost:8000`
- Dashboard: `http://localhost:5173`
